## 🗺️ Code Navigation Guide

### Where to Find Things in the Code

**Controllers:**
- Public features: `app/Http/Controllers/`
- Admin features: `app/Http/Controllers/Admin/`

**Models:**
- All models: `app/Models/`
- See relationships in each model file

**Views:**
- Public pages: `resources/views/pages/`
- Admin pages: `resources/views/admin/`
- Components: `resources/views/components/`

**Routes:**
- Public routes: `routes/web.php`
- Admin routes: `routes/admin.php`
- Chat routes: `routes/chat.php`
- Auth routes: `routes/auth.php`

**Database:**
- Migrations: `database/migrations/`
- Seeders: `database/seeders/`
- Database file: `database/database.sqlite`

**Frontend Assets:**
- CSS: `resources/css/`
- JavaScript: `resources/js/`
- Images: `public/images/`

**Configuration:**
- All config: `config/`
- Environment: `.env`

### Finding Information Quickly

**In Documentation:**
```
Ctrl+F / Cmd+F in your editor or browser
```

**Common Search Terms:**
- "Order" - Order processing information
- "Cart" - Shopping cart details
- "Chat" - Chat system information
- "User" - User management
- "Payment" - Payment processing
- "Email" - Email notifications
- "Database" - Database structure
- "Route" - URL routing
- "Model" - Data models

**In Code:**
```bash
# Search all files for a term
grep -r "OrderController" .

# Find files by name
find . -name "*Order*"

# Laravel's route list
php artisan route:list
```
